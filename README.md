# Calculator

A simple Calculator playable in the browser.

## How to use

Click the digits to enter a number, choose an operator (+, -, \*, ÷), enter a second number and press **=** to see the result. You can chain multiple operations (e.g. 12 + 3 + 4). Use the **AC** button to reset.
